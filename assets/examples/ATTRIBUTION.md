# Example images

- `source.png`: Eileen Collins, NASA astronaut photograph, distributed as `skimage.data.astronaut`. Public-domain US government image. Source: https://scikit-image.org/docs/stable/api/skimage.data.html#skimage.data.astronaut
- `target.jpg`: Rear Admiral Grace Hopper, US Navy photograph, distributed as Matplotlib sample data `grace_hopper.jpg`. Public-domain US government image. Source: https://matplotlib.org/stable/gallery/cbook/image_demo.html

These are sample inputs for educational experiments. Results are labelled as edited. The people pictured do not endorse this project.

- `sally.jpg`: NASA / Glenn Research Center, Sally Ride (1979), public domain. https://commons.wikimedia.org/wiki/File:Sally_Ride_1979.jpg
- `katherine.jpg`: NASA, Katherine Johnson (1966), original image, public domain. https://commons.wikimedia.org/wiki/File:Katherine_Johnson_at_NASA,_in_1966_-_Original.jpg
- `rotated.jpg`, `blurred.jpg`, `multiple-faces.jpg`: deterministic test transformations/composites of the credited portraits, generated by scripts/build_examples.py.
- `text-only.png`, `no-face.png`: locally drawn validation fixtures.
- `demo-result.jpg`: actual MorphLab output using Eileen Collins as source and Grace Hopper as target; explicitly an edited demonstration.

The source photographs have been resized for the local example gallery. The same credits are shown on the website’s How It Works page.
